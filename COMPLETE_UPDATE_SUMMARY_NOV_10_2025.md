### 2. Mind-Map Framework

**Status**: ✅ Integrated across all documentation + complete guide

**Core Principle**: Multi-time-scale cognitive architecture

**Three Levels**:
```
RARE ←―――――――――――――――――――――――――――→ FREQUENT

L0 (Foundation)     L1 (Implementation)    Dashboard (Session)
Abstract patterns   Concrete solutions    Immediate context
Days-weeks          Hours-days            Real-time
Test & validate     Enforce & gate        Execute & discard
```

**Why It Works**:
- Different update frequencies prevent interference
- Solves catastrophic forgetting at interface level
- Related findings by Google at model level
- Universal continual learning pattern

### 3. Failure Documentation

**Status**: ✅ Integrated across all documentation + complete guide

**Core Principle**: Failures contain 10-100× more information than successes

**Failure Hierarchy**:
```
Bug Patterns (L0)      ← Highest value (prevents bug classes)
Anti-Patterns (L0)     ← High value (guides architecture)
Failed Approaches (L0) ← Medium value (narrows solution space)
Edge Cases (L1)        ← Project value (specific handling)
```

**Why It Works**:
- Success: 1 bit ("true")
- Failure: N bits (full causal model)
- One failure prevents 3-10 similar errors
- Systematic constraint discovery

**Integration**:
- Main whitepaper: Formal contribution with examples
- Paradigm Shift: Information density paradigm
- Mixture of Memories: MoM optimization analysis
- README: Pyramid visual
- Startup Prompt: Priority guidance
- Complete guide: Taxonomy + workflows
